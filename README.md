# Huntley Homework Hero

In software engineering this year, myself and a group of two other poeple created a website called the Huntley Homework Hero.


[The project can be found here.](https://github.com/joveedez/SWE)


**Purpose**

The purpose of the website is to allow students to post homework questions even when they're not at school. Teachers are then able to respond to questions to provide explanations.

**Technologies**

We used VS Code, Flask (Python), HTML/CSS/JavaScript, and JSON to store our data.
